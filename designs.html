In-car infotainment
systems

In my role as UX Designer, I worked on in-car infotainment and entertainment system interfaces for premium automotive brands. Working within agile setups, I was heavily involved in designing and refining both low-fidelity screen layouts and high-fidelity wireframes, translating complex requirements into intuitive user flows.

Close collaboration with software engineers, product owners, and other stakeholders was key to aligning technical constraints with user-centric concepts, ensuring that UI components were feasible and well-integrated.

In addition, I conducted UI usability testing and interface heuristic evaluations to iteratively refine interface concepts, evaluating visual hierarchies and ensuring a seamless end-to-end user experience.
